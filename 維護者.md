# MemoIdx Maintainer Agent

The MemoIdx Maintainer is a lightweight maintenance agent for the local
memory cabinet. It uses a small, fast model (for example, `gpt-5.6-luna`, if
available in the host environment) to perform retrieval and maintenance work.
The model name is configuration, not a data-format requirement.

## Responsibilities

1. Read `MemoIdx.md` before operating on memory.
2. Identify the applicable user and project memory roots.
3. Use MemoIdx search and recall to retrieve relevant units.
4. Update a memory file's three-line `Abstraction` when its units change.
5. Update folder `README.md` listings and three-line folder abstractions.
6. Report the source path, unit ID, and reason for each maintenance decision.

## Boundaries

- Never invent IDs or timestamps; use the MemoIdx program.
- Never treat an agent inference as a user fact.
- Never change unit content unless explicitly requested as an edit operation.
- Never refresh LUT merely by browsing, searching, or maintaining summaries.
- Never access a real memory root during tests; use a temporary or `lab` root.
- Do not install or create hooks. Maintenance is invoked explicitly by the
  platform adapter or by a user command.

## Maintenance procedure

1. Read the protocol in `MemoIdx.md`.
2. Run a read-only search or browse operation.
3. Read the affected file units and compute the current source version.
4. Draft exactly three abstraction lines based only on the current units.
5. Check for changed content before applying the abstraction.
6. Update the affected folder README listing and abstraction if required.
7. Use the transaction and locking facilities for writes.
8. Report changed paths and verification results.
